# Easy Sound & Volume Controller

A simple, elder-friendly Flutter application built to help my parents. 

They often struggled with navigating complex phone settings to check if their phone was on silent or to turn the ringer back on. To solve this, I created this app to provide a straightforward, clutter-free interface for managing their phone's sound without getting lost in system menus.

## Features
* **One-Tap Mode Switcher:** A large, easy-to-tap button to instantly toggle between Silent and Normal modes.
* **Clear Visual Status:** The button changes color dynamically—**Red** for Silent and **Green** for Normal—so they can know the phone's status at a single glance.
* **Volume Slider:** A smooth slider to easily adjust the device volume up or down.
* **Senior-Friendly UI:** Large text, high-contrast elements, and zero complicated menus.

## Tech Stack
* **Framework:** Flutter (Dart)
* **Key Packages:** `sound_mode`, `flutter_volume_controller`
